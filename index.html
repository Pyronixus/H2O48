Comment Jouer à H2O48 ?

📖 Les Règles de Base

Le but du jeu est simple : fusionner les tuiles contenant des nombres identiques pour atteindre la tuile 2048 (et au-delà !).

  • Déplacement : Utilise les flèches directionnelles, les touches ZQSD/WASD, ou glisse ton doigt sur mobile pour déplacer toutes les tuiles.
  • Fusion : Quand deux tuiles portant le même nombre se percutent, elles fusionnent en une seule dont la valeur est doublée (ex: 2 + 2 = 4).
  • Fin de partie : La partie se termine si la grille est pleine et qu'aucun mouvement n'est possible.

⚙️ Les Paramètres

Adapte le jeu à ton style de jeu grâce au panneau de contrôle :

  • Grille : Modifie la taille du plateau (de 2x2 jusqu'à 8x8).
  • Objectif : Change le but à atteindre (2048, 4096, 8192... ou Infini).
  • Contrôles : Alterne entre différents modes de saisie (Flèches, ZQSD, Boutons virtuels).

🕹️ Les Modes de Jeu

Découvre des variantes uniques pour pimenter tes parties :

Normal

Le jeu de base classique et relaxant.

Chrono

60 secondes pour faire le meilleur score possible. Fusionner rapporte du temps bonus !

Négatifs

Des tuiles négatives apparaissent. Fusionne-les pour les éliminer ou perds des points !

Gravité

Les tuiles "tombent" constamment dans une direction qui change chaque minute.

Invisible

Les tuiles sont invisibles et n'apparaissent qu'une fraction de seconde !

Zen

Pas de stress, pas de game over. Le jeu nettoie les tuiles gênantes pour toi.

Hard

Le défi ultime combinant plusieurs modes extrêmes (Chrono + Négatifs + Gravité).
